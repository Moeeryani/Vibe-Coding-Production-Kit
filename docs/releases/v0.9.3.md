### Release automation without automatic approval

Stage 9 adds `vcp release-check <version>`.

Preview mode checks static release contracts without running npm packaging/publish-dry-run/install/update mechanics.

Run mode may execute:

- `npm pack --json`;
- `npm publish --dry-run --json`;
- local install smoke from the generated tarball;
- a local lifecycle smoke starting from the retained previous release tag;
- post-update framework/Doctor/idempotence checks.

It never executes:

- `npm publish`;
- tag creation, movement, deletion, or recreation;
- GitHub release creation;
- deployment.

A green report means the declared candidate mechanics passed. Actual publication and immutable tag creation remain HUMAN DECISION actions.

### Community profiles without executable plugins

Stage 10 adds `vcp plugins` and an opt-in declarative plugin model.

Selected bundles are local, text-only, versioned, digest-pinned, and explicitly granted capabilities. Guidance may enter bounded context; verification commands remain proposals and are never copied into `AGENTS.md` or executed automatically.

This does not implement a plugin runtime, remote marketplace, or native mobile profile support.
