# Security Profile

Authority: ACCEPTED

## Active profiles

The `baseline` profile is always active and does not need to be listed.

No additional project-sensitive profiles are active by default.

When repository evidence and accepted project intent make a profile applicable, add its exact identifier as a bullet here. Supported identifiers are documented in `docs/SECURITY-PROFILES.md`.

Profile selection records project security shape, not risk acceptance or compliance status. See `docs/SECURITY-PROFILES.md`.
